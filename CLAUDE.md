# CLAUDE.md

Guidance for Claude Code when working in this repository (a public Study Hub site for Grade 11 courses).

## PII / anonymity requirements

Never include real names (teachers, students, or anyone else), school/board names, school-board-hosted URLs (e.g. `*.tdsb.on.ca` or similar domains), or references tied to a real class schedule (specific quiz dates, days of the week, "Monday's quiz," "the quiz on Wednesday," etc.) — including in page text, subtitles, callouts, tile descriptions, filenames, and any other generated document (quizzes, docx/pdf handouts, etc.), not just the main HTML pages. Sanitize all such dates: use relative, generic phrasing instead (e.g. "the upcoming quiz," "coming up soon") rather than any calendar date or weekday. Keep all content and links fully generic/anonymous since this site is public.
