Translations of Functions

MCR3U1 · Unit 2 · Section 2.3

g(x) = f(x ± d) ± c is the parent f shifted without changing its shape. Inside the bracket moves it horizontally (and opposite to the sign); outside moves it vertically (and matches the sign).

The method

  1. Identify the parent function (x, x², √x or 1/x) and write down a few of its key points.
  2. Read the inside number: f(x − d) shifts right d, f(x + d) shifts left d.
  3. Read the outside number: f(x) + c shifts up c, f(x) − c shifts down c.
  4. Move each key point: (x, y) → (x + d, y + c). Plot the image points and draw the shape.
  5. Domain and range: add d to the parent's domain restriction, and c to its range restriction. Asymptotes move too.
