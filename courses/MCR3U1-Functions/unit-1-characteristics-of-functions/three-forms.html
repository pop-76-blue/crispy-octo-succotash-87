Three Forms of a Quadratic

MCR3U1 · Unit 1 · Section 1.6

Factored: a(x − r)(x − s)  ·  Standard: ax² + bx + c  ·  Vertex: a(x − h)² + k.
Set the roots r and s and the stretch a below. All three forms update together.

What to notice

  • In standard form, b = −a(r + s) and c = a·rs.
  • The vertex always sits halfway between the roots: h = (r + s) ÷ 2.
  • Changing a never moves the roots. It only stretches the parabola (or flips it when negative).
  • Set r = s and the parabola just touches the x-axis: a double root.

Not every quadratic can be written in factored form with real numbers. When the vertex is above the x-axis and the parabola opens up, there are no x-intercepts, so only standard and vertex form exist.

Try this: Without moving anything, predict the standard form of a = 2, r = −1, s = 3 (work out b = −a(r + s) and c = a·rs). Then set the sliders and check. Next, set r = s = 2 and explain what happens to the vertex.
