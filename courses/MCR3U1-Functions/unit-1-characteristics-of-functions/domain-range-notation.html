Domain and Range

MCR3U1 · Unit 1 · Sections 1.1 and 1.2

A relation pairs inputs (the domain) with outputs (the range). It is a function when every input has exactly one output.

The procedure

  1. Is it a function? Pairs: does any x repeat with different y's? Graph: vertical line test. Equation: can one x give two y's?
  2. Find the domain. From a graph or list, read the x-values. From an equation, rule out what breaks it: division by zero, or a negative under a square root.
  3. Find the range. Read the y-values. From an equation use the vertex (parabola), the starting point (square root) or the asymptote (reciprocal).
  4. Write it in set notation, for example {y ∈ ℝ | y ≥ −7}.

Set notation cheat sheet

  • { } enclose the elements of a set, separated by commas
  • | means "such that"
  • ∈ means "is an element of"
  • ℝ is the real numbers; ℤ (or I) is the integers
  • Example: {x ∈ ℝ | x ≥ 5} reads "all real x such that x is at least 5"
