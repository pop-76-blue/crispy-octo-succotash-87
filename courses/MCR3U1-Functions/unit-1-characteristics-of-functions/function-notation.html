Function Notation

MCR3U1 · Unit 1 · Section 1.2

y = f(x) is read "y equals f of x". It says y is a function of x, and f(3) is the output when the input is 3, which is the point (3, f(3)).

The procedure

  1. Evaluate: replace every x in the rule with the input, then simplify. Use brackets for negative inputs.
  2. Make a table: do this for each input, then write the ordered pairs (x, f(x)).
  3. Convert an equation: solve for y first, then rename y as f(x).
  4. Model a situation: start value + (rate × input). Then use it to evaluate, or set it equal to a number and solve.
