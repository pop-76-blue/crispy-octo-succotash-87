Operations with Radicals

MCR3U1 · Unit 1 · Section 1.4

Radicals behave like algebraic terms. √3 is like the variable x: you can combine like radicals, and multiplying works the way it does with brackets.

The procedure

  1. Add or subtract: simplify every radical first, then combine only radicals with the same number under the root.
  2. Multiply: multiply the coefficients, multiply the radicands, then simplify. With brackets, distribute or FOIL.
  3. Divide: divide coefficients, divide radicands, simplify.
  4. Rationalize: if a radical is left in a denominator, multiply top and bottom by that radical.
