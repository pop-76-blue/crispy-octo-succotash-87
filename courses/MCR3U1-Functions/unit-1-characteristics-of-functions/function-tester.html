Is It a Function?

MCR3U1 · Unit 1 · Section 1.1

Vertical line test: a relation is a function if every vertical line crosses its graph at most once. Slide the vertical line across each graph and watch how many points it hits.

Slide the line

Check a set of ordered pairs

Type pairs like (1, 2), (1, 5), (3, 4). The checker finds the domain and range and tests the function rule.

Try this: Before sliding, decide which of the five graphs are functions and write down why. Then slide the line across x = 0 on the sideways parabola and the circle. What is the largest number of crossings you see for each? For the pairs checker, enter (1, 2), (3, 2), (5, 2) and explain why it is a function even though every y is the same.
