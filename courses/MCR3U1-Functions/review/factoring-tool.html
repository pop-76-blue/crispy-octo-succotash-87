MCR3U1 · Prerequisite Review

Before anything else: always check for a GCF first. Every method below assumes you've already pulled out the greatest common factor, if there is one. Skipping this step is the most common factoring mistake.

The decision tree

  • Look for a GCF
  • 2 terms → Difference of squares (a² − b²)
  • 3 terms → Trinomial (simple or complex)
  • 4 terms → Grouping

Perfect square trinomials — finding a missing value

A trinomial ax² + bx + c is a perfect square exactly when b² = 4ac. That's the test to use whenever a question asks you to find the value of k that makes a trinomial a perfect square — set up that equation and solve for the missing piece.
