1. Linear Functions

y = mx + b — m is slope (rise/run), b is the y-intercept.

  1. Given two points, find slope: m = (y₂ − y₁) / (x₂ − x₁)
  2. Substitute one point into y = mx + b and solve for b — or use point-slope form: y − y₁ = m(x − x₁)
  3. Parallel lines: same slope. Perpendicular lines: slopes multiply to −1.
Line through (5, 5) and (−10, −4): m = 9/15 = 3/5. Sub (5,5): 5 = 3/5(5) + b → b = 2. y = (3/5)x + 2

2. Linear Systems

  1. Substitution: use when a variable is already isolated (or easy to isolate).
  2. Elimination: use when coefficients already match, or can be scaled to match easily — multiply one or both equations, then add or subtract to cancel a variable.
  3. Solve for the first variable, then substitute back to find the second. Check both equations.
3x − 5y = −4 and 2x − 3y = −2: ×2 and ×3 to match x-coefficients → 6x − 10y = −8, 6x − 9y = −6 → subtract → −y = −2 → y = 2, x = 2.

3. Expanding & Simplifying

  1. Distribute every term inside brackets by whatever's multiplying the bracket.
  2. For (a + b)², expand as (a + b)(a + b) — don't forget the middle term.
  3. Combine like terms at the end, and watch signs when subtracting a whole bracket.
2(3x − 2)² − 3(x − 1)(x + 5) = 2(9x² − 12x + 4) − 3(x² + 4x − 5) = 18x² − 24x + 8 − 3x² − 12x + 15 = 15x² − 36x + 23

4. Factoring

  1. Always look for a GCF first.
  2. 2 terms → difference of squares: a² − b² = (a − b)(a + b)
  3. 3 terms → trinomial: find two numbers with product = a×c, sum = b. Simple (a=1): write directly. Complex (a≠1): split the middle term and group.
  4. 4 terms → group into pairs, common-factor each, factor out the shared binomial.
  5. Perfect square trinomial "find k" questions: use b² = 4ac and solve for the missing value.
9x² + kx + 25 is a perfect square: k² = 4(9)(25) = 900 → k = ±30

5. Quadratics

  1. Vertex form: y = a(x − h)² + k. Vertex (h, k), axis of symmetry x = h, opens up if a > 0, down if a < 0.
  2. y-intercept: substitute x = 0.
  3. To get vertex form from y = x² + bx + c: complete the square — take half of b, square it, add and subtract it, then rewrite the perfect square trinomial as (x + b/2)².
  4. Roots from vertex form: set y = 0 and solve (x − h)² = −k, so x = h ± √(−k) (only if −k ≥ 0).
y = x² + 10x + 20 → (x + 5)² − 5. Vertex (−5, −5). Roots: x = −5 ± √5

6. Exponents

  1. Same base only: am × an = am+n, am ÷ an = am−n
  2. Power of a power: (am)n = amn
  3. Negative exponent: a−n = 1/an. Zero exponent: a⁰ = 1.
  4. Always follow order of operations for anything outside the exponent rules.
(4¹⁵)⁵ × (4⁻¹²)⁶ = 4⁷⁵ × 4⁻⁷² = 4³ = 64
