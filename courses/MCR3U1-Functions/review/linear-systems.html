Substitution vs. Elimination

MCR3U1 · Prerequisite Review

Both methods always work on any linear system. The question isn't "which one is correct" — it's "which one is less work for this system."

Same system, two methods

System: y = 2x + 4 and y = −x + 1

Substitution

Use this when a variable is already isolated (or easy to isolate) in one equation.

Both equations are already solved for y, so set them equal:
2x + 4 = −x + 1
3x = −3 → x = −1
y = 2(−1) + 4 = 2
(x, y) = (−1, 2)

Elimination

Use this when coefficients can be matched (or easily scaled to match) so a variable cancels.

Rewrite in standard form: 2x − y = −4 and x + y = 1
Add the equations: the y-terms cancel
3x = −3 → x = −1, then y = 2
(x, y) = (−1, 2)

Same answer either way — substitution was less rewriting here because both equations already isolated y.

A system built for elimination

System: 3x − 5y = −4 and 2x − 3y = −2

Why not substitution?

Neither equation has a variable with a coefficient of 1 — isolating x or y means introducing fractions right away, which is more error-prone.

Elimination

Multiply to match coefficients: ×2 the first, ×3 the second
6x − 10y = −8
6x − 9y = −6
Subtract: −y = −2 → y = 2
Substitute back: 3x − 5(2) = −4 → x = 2
(x, y) = (2, 2)

Decide first

For each system, pick the method you'd reach for first, then check the reasoning.
