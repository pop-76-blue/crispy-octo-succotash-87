Positional Number Systems

Unit 1  ·  1.1 The Decimal System & intro to 1.2 The Binary System

Why "positional" matters

In the number system we use every day, a digit's value depends on where it sits. The digit 2 in 72,376 is worth 2,000. The same digit 2 in 123 is worth only 20. Moving a digit one spot to the left multiplies its value by the base of the system — 10, in decimal.

This wasn't always how numbers worked. Roman numerals aren't positional — X means 10 no matter where it appears in a string of symbols. That's exactly why arithmetic with Roman numerals is painful and arithmetic with Hindu-Arabic numerals (what we use) is easy enough to hand off to a machine.

Every number system built this way — decimal, binary, and later hexadecimal and octal — follows the same rule: a number equals the sum of each digit multiplied by the base raised to that digit's position, counting from position 0 on the right.
