What each operation does

AND: result bit is 1 only if both A and B have a 1 in that column.
OR: result bit is 1 if either A or B (or both) has a 1.
XOR: result bit is 1 if exactly one of A or B has a 1 — not both.
NOT(A) / NOT(B): flips every bit of a single register — every 0 becomes a 1, and every 1 becomes a 0.
SHL(A): shifts every bit of A one place left, drops the leftmost bit, and inserts a 0 on the right — the same effect as multiplying A by 2.
SHR(A): shifts every bit of A one place right, drops the rightmost bit, and inserts a 0 on the left — the same effect as integer division of A by 2.

Try this: Set A to 0011 1000 (56) and B to 0001 0101 (21). Before pressing Walk through it, predict every column of the AND result on paper — then watch it build and check yourself column by column. Afterward, try NOT(A) and SHL(A), clicking a few columns in each to see how the explanation changes.
