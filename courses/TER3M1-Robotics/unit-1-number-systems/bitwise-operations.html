Bitwise Operations

Unit 1  ·  1.2.8 Bitwise Operations (AND, OR, XOR, NOT, SHL, SHR)

Logical operations (AND, OR, XOR) compare two registers column by column — no carrying between positions. NOT works on a single register, flipping every bit. Shift operations (SHL, SHR) also work on a single register, sliding every bit one position and dropping whatever falls off the end.

What each operation does

AND: result bit is 1 only if both A and B have a 1 in that position.
OR: result bit is 1 if either A or B (or both) has a 1.
XOR: result bit is 1 if exactly one of A or B has a 1 — not both.
NOT(A) / NOT(B): flips every bit of a single register — every 0 becomes a 1, and every 1 becomes a 0.
SHL(A): shifts every bit of A one place left, drops the leftmost bit, and inserts a 0 on the right. This has the same effect as multiplying A by 2.
SHR(A): shifts every bit of A one place right, drops the rightmost bit, and inserts a 0 on the left. This has the same effect as integer division of A by 2.

Try this: Set A to 0011 1000 (56) and B to 0001 0101 (21). Predict the AND result column by column on paper, then check it. Try NOT(A) and predict its decimal value before checking — notice it's not simply "256 minus A". Afterward, switch to SHL(A) twice in a row and confirm it doubles A's decimal value each time.
