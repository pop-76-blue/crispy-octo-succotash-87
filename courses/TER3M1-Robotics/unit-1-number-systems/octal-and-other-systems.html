Octal & Other Number Systems

Unit 1  ·  1.4 Other Systems

Every number system you've seen so far — decimal, binary, hex — follows the exact same rule: pick a base N, allow digits from 0 up to N−1, and a number's value is the sum of each digit times a power of N. Octal (base 8) is just one more example, and it matters here because, like hex, 8 is a power of 2 (23 = 8) — so octal digits also convert to binary in fixed-size groups, this time 3 bits at a time instead of 4.

Generalizing to any base N

Nothing about place value actually requires base 2, 8, 10, or 16 specifically. For any base N > 1, digits run from 0 to N−1 (using letters once you pass 9, the same way hex does), and a number's value is still just the sum of digit × Nposition. For example, in base 18, the digits 9HA3 mean: 9×18³ + 17×18² + 10×18&sup9; + 3×18⁰ (H is the 17th letter-digit, A is the 10th).
