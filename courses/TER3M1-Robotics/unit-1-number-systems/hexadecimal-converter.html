Hexadecimal Converter

Unit 1  ·  1.3 The Hexadecimal System · 1.3.1–1.3.3 Conversions

Hexadecimal ("hex") is base 16. Since we only have ten digit symbols, hex borrows the letters A–F to represent 10–15. Programmers use hex constantly — not because computers use base 16 internally (they don't; it's still all binary underneath), but because hex is a compact, human-friendly shorthand for binary. The reason it lines up so cleanly: one hex digit represents exactly one nibble (4 bits), since 24 = 16.
