1 bit
bit

The smallest unit of information a computer stores — a single 0 or 1. Physically, it's usually a voltage level (roughly 0V or 5V) that a circuit reads as low or high.

4 bits
nibble

Half a byte. One nibble holds exactly enough bits to represent one hexadecimal digit (0 through F) — that's why hex and binary pair up so cleanly.

8 bits
byte

The standard unit for a single character of text. With 8 bits you get 28 = 256 distinct patterns — exactly enough to cover the full ASCII table.

16 bits (2 bytes)
word

Two bytes together. The exact meaning of "word" varies more by system than the other terms, but in this course we use 2 bytes.

32 bits (4 bytes)
dword

Short for "double word" — 4 bytes. This is the size Java uses for its int type.

64 bits (8 bytes)
qword

Short for "quadruple word" — 8 bytes. Java's long and double types both use 8 bytes.
