Measuring Voltage & Kirchhoff's Voltage Law

Unit 3  ·  Lab 7a–c — the third multimeter mode, and the rule that governs it

Kirchhoff's Voltage Law: the voltage supplied to a circuit equals the sum of every voltage drop around any complete loop.

VA = V1 + V2 + V3 + … + Vn

Every time current passes through a component, it "spends" some voltage — that's a voltage drop. In a series circuit, those drops add up to exactly the supply voltage. In a parallel circuit, every branch sees the same voltage drop, regardless of that branch's resistance — it's the current through each branch that differs instead, so V = IR still holds for each one individually.

This is the mirror image of what you already found for current: in series, current is identical everywhere and voltage splits; in parallel, voltage is identical everywhere and current splits.

Measuring voltage

To measure a voltage drop, the multimeter must be set to Voltage and connected in parallel with the component being measured, with the circuit's power still on — the opposite wiring from current mode, but like current mode, the circuit stays powered (unlike resistance mode, which needs the power removed).
