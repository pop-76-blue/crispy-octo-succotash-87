Labs 10b & 10c — Complex Logical Expressions

Unit 3  ·  Digital Circuits Part 2 — turning an expression into a chain of chips

Both labs follow the same recipe. Task 1 is in TinkerCAD: build the expression from AND (7408), OR (7432) and NOT (7404) chips, write the truth table on paper, and check every row against the LED, with a multimeter showing about 18 mA through it. Task 2 is the physical circuit, wired exactly like your TinkerCAD design (physical resistor values may differ a little). You only need to do one lab (10b or 10c) — the method below is the same for both.

StepWhat to do
1. Decide the groupingWork out which operator happens first (see the order-of-operations note below).
2. Break into gatesEvery operator becomes one gate. Name each sub-result (these become the extra columns in your truth table).
3. Truth table8 rows for 3 variables. Add one column per gate so you can debug the circuit one gate at a time.
4. Chain the chipsEach gate's output leg feeds the next gate's input leg. Power every chip: Vcc to leg 14, GND to leg 7.
5. LED + resistorThe last chip drives the LED through a resistor; that chip's 45Ω is in series with it (calculator below).

A note on order of operations

Both lab expressions are written without brackets, so you have to decide how to group them. The widely used rule is NOT first, then AND, then OR. That settles Lab 10b. Lab 10c is harder: P XNOR Q NAND R has no single universal reading, because it mixes XOR-type and AND-type operators. Below, both readings are shown with the rule each one follows — use the order-of-operations rule from your Unit 2 notes (section 2.5) to choose, or ask in class. The two readings give different truth tables, so it does matter.

Gate plan for the reading you selected

The labs only provide AND, OR and NOT chips, so XNOR has to be built from them: P XNOR Q = (P AND Q) OR ((NOT P) AND (NOT Q)). Try the four combinations of P and Q on paper to see both sides agree. This is one valid design, not the only one — if you find a shorter one that matches the truth table, use it.
