Resistor Color Code Decoder

Unit 3  ·  Reading resistance from resistor colours

Resistors used in these labs have 4 colour bands, read left to right, with gold or silver always on the right. The first two bands are digits; the third is a multiplier (a power of 10); the fourth is the tolerance.

ColourDigitMultiplier
Black0×100
Brown1×101
Red2×102
Orange3×103
Yellow4×104
Green5×105
Blue6×106
Violet7×107
Gray8×108
White9×109

Pick the four bands

Try this: Set bands to Red, Violet, Yellow, Gold and predict the resistance and tolerance range before checking — then compare against the 2.2MΩ worked example from class.
