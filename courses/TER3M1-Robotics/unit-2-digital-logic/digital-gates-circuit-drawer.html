Digital Gates — Circuit Drawer

Unit 2  ·  2.8 Digital Gates — from a logical expression to a gate diagram, and back to a test

In a circuit, each logical operator becomes a gate. A gate takes one or two input wires and produces one output wire. Following the order of operations (2.5) tells you which gate gets drawn first — the same order you use to evaluate the expression.

OperatorGateOutput is 1 when…
ANDboth inputs are 1
ORat least one input is 1
NOTthe input is 0 (it flips the value)
XORexactly one input is 1

NAND, NOR and XNOR are drawn as the gate followed by a NOT gate.
