Naming Molecular (Covalent) Compounds

Unit 2: Chemical Nomenclature · The mono-di-tri prefix system, for two nonmetals.

This system is used for compounds made of two nonmetals. Greek prefixes show exactly how many atoms of each element are in the formula — unlike ionic compounds, you can't predict the formula from charges.

Prefix table

NumberPrefixNumberPrefix
1mono5penta
2di6hexa
3tri7hepta
4tetra8octa
Rule: name the first element with its full name (prefix "mono-" is usually dropped if there's only one of the first element), then the second element gets a prefix + its stem + "-ide." Example: CO₂ → carbon dioxide. N₂O₅ → dinitrogen pentoxide. (Note: "penta-oxide" drops the "a" before a vowel → "pentoxide".)
