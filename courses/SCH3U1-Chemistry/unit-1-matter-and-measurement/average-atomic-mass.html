Average Atomic Mass

Unit 1: Measurement & Matter · Isotopes and the weighted average on the periodic table.

Isotopes of an element have the same number of protons but a different number of neutrons — so they have different masses. The mass shown on the periodic table is a weighted average of all the naturally occurring isotopes, based on how common each one is.

The formula

average atomic mass = (mass₁ × fractional abundance₁) + (mass₂ × fractional abundance₂) + …

Turn each percent into a decimal first (75% → 0.75), and check that all the percentages add to 100%.
