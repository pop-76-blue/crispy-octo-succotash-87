3.5 Using Newton's Laws

Putting all three laws together: tension, connected objects, and combining forces with kinematics.

Tension and Connected Objects

In this course, ropes and strings are assumed to be massless and non-stretching. Two useful consequences follow:

  • The tension is the same throughout a single rope or string — it pulls equally hard at both ends.
  • A pulley only changes the direction of a force. It never changes the magnitude of the tension.
  • Objects connected by a taut string move together, sharing the exact same acceleration.

This lets you solve connected-object problems in two steps: treat everything as one combined object to find the shared acceleration, then look at just one piece at a time to find the tension in a particular rope.

Try it: Train of Connected Objects

Three objects are tied in a line with ropes and pulled by a single applied force at the front (frictionless surface, matching the textbook's simplifying assumption).

Try this: Match the sliders to the textbook example: 12 kg, 11 kg, 7 kg, and 120 N applied. Before reading the table, calculate the shared acceleration by hand (treat all three as one 30.0 kg object), then find the tension in Rope B (between masses 1 and 2, isolating the combined 18.0 kg of masses 2+3) and Rope A (between masses 2 and 3, isolating mass 3 alone). You should get 72 N and 28 N.

Tension Doesn't Double (or Cancel)

A common mistake: assuming that splitting a weight across two strings, or redirecting it with a pulley, changes the tension. It doesn't — as long as the system is in equilibrium, the string(s) only ever need to supply enough tension to support the actual weight.

A 120 N object hangs from one string.
Tension = 120 N
The same object hangs from one string over a pulley (just redirected).
Tension = 120 N
The same object is held by a string that passes over a pulley to a second, identical hanging object acting as a counterweight.
Tension = 120 N (the second object is just doing the job the wall or your hand used to do)

Combining Kinematics with Newton's Laws

The Big Five equations from Unit 1 only work while acceleration is constant. Since Fnet = ma, that means they only work while the net force stays constant too. If a problem has several phases (e.g. pushing off, then coasting, then braking), you need to treat each phase separately — find the acceleration for that phase using Newton's second law, then apply a kinematics equation just within that phase.

Need to solve one of those phases? Use the Big Five solver from Unit 1 once you know that phase's acceleration.
