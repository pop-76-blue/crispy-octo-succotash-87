2.1 Introduction to Vectors

Representing vectors, and adding them graphically using the tip-to-tail method.

Recall from Unit 1: a scalar has only magnitude (size), while a vector has both magnitude and direction. In two dimensions, we draw a vector as an arrow: the length represents the magnitude, and the arrow points in the direction.

We write a 2D direction either as a compass-style bearing in brackets, like 65 km [E25°N] (meaning: start facing East, then rotate 25° toward North), or using an angle measured from a reference axis, like 65 km at 25° above the horizontal. Your teacher's notation may use one or the other — both describe the same vector.

Adding Vectors: Tip-to-Tail

To add two vectors graphically, draw the first vector, then start the second vector's tail at the tip (arrowhead) of the first. The resultant vector is the arrow drawn from the very start (the tail of the first vector) to the very end (the tip of the second vector).

This works no matter what order you add them in — A + B gives the same resultant as B + A.
