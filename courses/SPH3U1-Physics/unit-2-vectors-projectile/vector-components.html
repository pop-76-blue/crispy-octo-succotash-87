2.2 Vector Components

Resolving a vector into x and y pieces — and using them to add vectors algebraically.

Any vector can be broken into two perpendicular pieces: an x-component and a y-component. If a vector has magnitude v and angle θ measured from the positive x-axis (East):

vx = v cosθ     vy = v sinθ

To add two (or more) vectors algebraically: resolve each into components, add the x-components together and add the y-components together, then recombine the totals into a resultant magnitude and angle:

R = √(Rx² + Ry²)     θ = tan-1(Ry / Rx)

This is usually faster and more precise than drawing a scale diagram, especially once you're adding more than two vectors.
